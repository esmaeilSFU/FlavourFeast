# Gallery automation

`gallery.html` no longer has hand-written photo/video entries. It renders
itself from `gallery-data.js`, which is auto-generated by
`generate-gallery-data.js` from whatever is actually in `assets/images/*`
and `assets/videos/*`.

## To add or remove gallery photos/videos

1. Add or delete files inside `assets/images/<FolderName>/` (any `.jpg`) or
   `assets/videos/` (`.mp4`, with a matching thumbnail in
   `assets/videos/thumbnail/<same-name>.png`).
2. Commit and push to `main` as usual.

That's it. `.github/workflows/update-gallery.yml` runs automatically on
that push, regenerates `gallery-data.js`, and commits it back — the live
site picks up the change on the next deploy with no manual HTML editing.

Notes:
- `GeneralPhotos` always appears first; other folders are appended
  alphabetically. To change this order, edit `PRIORITY_FOLDERS` in
  `generate-gallery-data.js`.
- A video is only included once both its `.mp4` and matching thumbnail
  exist — so a video added without a thumbnail (or vice versa) is silently
  skipped rather than showing a broken placeholder. Run the script locally
  (`node scripts/generate-gallery-data.js`) to see the skip warning.
- The `assets/images/hero` folder is excluded (site chrome, not gallery
  content).
